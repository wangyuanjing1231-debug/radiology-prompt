# 子宫内膜癌 MRI 看片清单

依据：ESUR 2019 子宫内膜癌 MRI 指南；分期默认 FIGO 2009（纯影像可判断）。FIGO 2023 的分层依赖组织学与分子分型，MRI 只能给出解剖分期。

## 0. 阅片前
- TCT（宫颈液基细胞学）「未见上皮内病变细胞或恶性细胞」只针对宫颈表面细胞，不能排除子宫内膜癌，与临床诊断不矛盾。
- 确认内膜癌诊断来源（诊刮 / 宫腔镜活检 / 临床拟诊）。

## 1. 检查技术
- 矢状位 T2WI、垂直宫腔长轴的斜轴位高分辨 T2WI（判断肌层浸润的关键层面）
- DWI + ADC（肿瘤 DWI 高、ADC 低；只看 DWI 可能是 T2 穿透效应）
- DCE 动态增强
- 大视野轴位覆盖至肾静脉水平（评估腹主动脉旁淋巴结）

## 2. 子宫
- 大小、位置（前倾 / 后倾）
- 合并肌瘤、腺肌症（会干扰肌层浸润判断）

## 3. 原发灶
- 位置（宫腔哪一侧 / 宫角 / 宫底 / 下段）、三径大小
- T2 信号、DWI/ADC、强化方式（不均匀、无强化坏死区）
- 核对与超声所见是否为同一病灶（大小差异大时确认不是肌瘤）

## 4. 肌层浸润深度 → IA / IB
- < 1/2 肌层 → IA；≥ 1/2 → IB
- 看结合带完整性、DCE 早期内膜下强化带是否中断
- 若已有淋巴结转移（IIIC），深度不改变分期，但仍应描述

## 5. 宫颈间质 → II
- 宫颈间质（致密纤维基质）T2 低信号环是否中断
- 仅宫颈管黏膜受累不算 II 期

## 6. 浆膜、附件 → IIIA
- 子宫外缘是否光整，附件区有无肿块

## 7. 阴道、宫旁 → IIIB

## 8. 膀胱、直肠 → IVA
- 与子宫间脂肪间隙；黏膜是否受侵
- 充盈不佳时写明是否有壁增厚，否则「建议复查」无对象

## 9. 淋巴结 → IIIC1 / IIIC2 / IVB
- 盆腔（髂总、髂内、髂外、闭孔、骶前）：属区域淋巴结 → IIIC1，不是远处转移
- 腹主动脉旁（主动脉分叉以上）：区域淋巴结 → IIIC2，不是远处转移
- 腹股沟及其他腹腔内淋巴结 → IVB（远处转移）
- 短径阈值：盆腔 > 8mm，腹主动脉旁 > 10mm
- 卡在阈值附近时看：形态偏圆、坏死 / 环形强化、DWI 信号与已知转移灶相近
- 腹股沟：短径、淋巴门脂肪是否存在
- 腹主动脉旁可疑时，结论可建议 PET-CT

## 10. 腹膜、腹水 → IVB
- 盆腔积液量、腹膜结节、网膜

## 11. 骨 → IVB
- 关键看 T1 不压脂：转移灶低于肌肉 / 椎间盘信号，并 DWI 高、ADC 低
- 仅增强不均、T1 与 T2 压脂正常 → 多为骨髓分布不均
- 骶髂关节髂骨面关节面下信号 → 致密性髂骨炎或退变的典型部位

## 12. 附见（只写进结论最后一段）
- 胃、肾、肝等视野内其他器官
- 肿瘤患者胃壁增厚：考虑加「必要时胃镜检查」
