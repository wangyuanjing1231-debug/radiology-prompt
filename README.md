# radiology-prompt

放射科语音流报告的规矩仓库。借鉴 OpenClaw 工作区的分层：

| 层 | 文件 | 说明 |
|---|---|---|
| 核心规矩 | `prompt-en.md`（放进 Gemini 技能的版本）、`prompt.md`（中文对照） | 只有这一层同步给 Gemini |
| 独立版（不用网页） | `prompt-a-en.md` / `prompt-a.md`（A：代码框外加一行「改动：」列出纠正和补写）、`prompt-c-en.md` / `prompt-c.md`（C：不标任何改动） | 换电脑、手边没有网页时用。和核心规矩的区别只在输出格式：代码框里不写标题、不加括号标记，每行开头两个全角空格，描述和结论之间空一行，复制后直接粘进 PACS；写法规则 1–10 与核心规矩相同。还在试用，看效果再定留哪个 |
| 候选经验 | `candidates.md` | 用的时候发现的问题和习惯写法，不同步；攒够、确认了再升级进核心规矩 |
| 工具 | Admin 上 `D:\AI\写报告包`（不在仓库） | 双击「启动」：回填热键（F10 覆盖 / ` 追加，只把描述和结论切开填两个框）、Pixel 同步（手机文字到电脑、图片两个方向，走 adb）、PixPin 截图；路径都相对包自己算，整个文件夹拷到别的电脑也能用。真机另外常驻一份同样只切分的热键 `D:\AI\pacs_autofill.ahk` |
| 记录 | （以后再建） | AI 初稿、自己改的、最终报告对照，用来反推规矩 |

分工：聊天里的 Claude 维护规矩和经验；YJW 上的 Antigravity 把核心规矩同步进 Gemini 技能并回读核对。

用法（2026-11-07 起）：Gemini 网页，技能正文是 `prompt-c-en.md`（C 版，直接出干净报告）；一个病人一个新对话 → 复制代码框 → Pixel 同步到电脑 → PACS 里按 F10。

点选网页那段尝试（2026-10-18 至 11-02，红蓝标注 + 点选删除 + 清洗后回填，用了约 40～50 个病人）停用了，留档在 `legacy/`：`baogao-v4.6.html`（网页最后一版）、`pacs_autofill-v4.6.ahk` 和 `clean_lib-v4.6.ahk`（带清洗、F9 收藏、回填记录的旧热键）。停用原因：强模型出的稿基本不用改，C 版直接出干净格式后，网页和清洗只剩多一步；网页又绑在一台电脑上，换电脑就要同步。

v3.8 及以前的旧提示词在 `legacy/`，只作参考，不再使用。

## 版本号

当前：Gemini 技能用 v4.3-C（2026-11-02 起；仓库里已是 v4.3-C2，还没同步进技能）· 规矩 v4.3 · 独立版 v4.3-A / v4.3-C2 · 网页 v4.6 已停用

- 哪个文件实际改了才升哪个的号，没改的不动。规矩写在文件第一行，网页写在标题和顶部提示行。
- 独立版的号跟着核心规矩走（v4.3 → v4.3-A / v4.3-C）；核心规矩的写法规则改了，独立版要一起改。
- 核对同步：Gemini 技能正文第一行对照这里的版本，对上了就是同步好了。
- 规矩改动需要网页配合时，先改网页、再改规矩；网页始终兼容旧写法，所以网页不比规矩旧就不会出错。
